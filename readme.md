# The project
I just want to learn about Python (tools and such, and some of the language quirks), FastAPI, security, auth and K8, so I created this project around a small data model I've been working on

At first I'm just going to make a small CRUD API with maybe 5-10 endpoints, then I'm going to concentrate on auth, security and K8. In the future maybe a recommendation engine
